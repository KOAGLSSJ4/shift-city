# Roadmap: Unreal version

1. **Compile and run** the plugin on the Vehicle template (docs/SETUP.md). Fix any first-build errors.
2. **First street vertical slice** (docs/FIRST-STREET.md): golden hour + wet night, one job end to end.
3. **Cockpit car:** import the free Corolla-with-interior; set up the in-car camera, mirrors and a dashboard map.
4. **Menus in UMG:** main menu (Story / Free Ride / Arcade), garage and goals. They call the Blueprint functions on the economy subsystem.
5. **Traffic:** ZoneGraph / Mass traffic or simple spline-following AI, plus traffic lights.
6. **Arcade Rush** level: endless highway, lane changes, coins, near-miss streaks. Logic ported from the browser version.
7. **Passengers:** characters (Mixamo or MetaHuman) waiting at stops, dialogue lines, ratings and tips.
8. **Fictional car designs** for every garage tier (needed before any paid release).
9. **Steam page and demo build.** The browser version links to the Steam page.
